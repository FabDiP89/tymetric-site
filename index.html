Domande Frequenti

Tutto quello che devi sapere per iniziare con Tymetric

Come funziona l'installazione On-Premise?

Tymetric è progettato con algoritmi proprietari ottimizzati che non richiedono server esterni dedicati, garantendo massima efficienza e piena conformità GDPR. Tutti i dati sensibili rimangono all'interno della vostra infrastruttura, senza dipendenze da servizi cloud di terze parti.

È compatibile con il mio gestionale HR attuale?

Assolutamente sì. Tymetric è progettato per integrarsi via API o flussi file (CSV/XML) con i principali software HR e paghe. Durante la fase di setup configuriamo i connettori specifici per la tua azienda.

Come gestite le regole del CCNL Sanità?

Il motore di regole di Tymetric include nativamente i vincoli del CCNL Sanità Pubblica e Privata (riposi, notti massime, monte ore). Inoltre, è possibile configurare regole integrative specifiche per la vostra struttura o accordi sindacali interni.

È possibile vedere il software in azione prima dell'acquisto?

Sì, organizziamo sessioni dimostrative personalizzate per mostrarvi le potenzialità del software. È inoltre possibile attivare un progetto pilota su un singolo reparto per valutare l'efficacia sul campo prima del rollout completo.
